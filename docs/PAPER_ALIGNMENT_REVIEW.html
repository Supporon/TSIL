按文件展开修改依据

src/tsil_loss.py · 完整 MSE 加固定残差矩惩罚

预测与原始标签相减得到 e；各谓词独立 Frobenius 归一化；直接计算 Phiᵀe/B 后加权平方，不构造 B×B Gram。beta 是验证集选定的常量。手算反例：旧值 2.375 → 新值 3.0625，与论文一致。

src/temporal_predicates.py · 恢复六个原始描述符

Cycle 在市场收益的时间轴 FFT，使用全局交易日的 sin/cos；Phase 使用个股收益 FFT 和 modulo。Momentum 为对数价格比；Volatility、Distribution 使用原始收益总体矩。Timestamp 为固定 OneHot。

src/predicate_data.py · 独立、因果的原始历史缓存

从 Qlib close 读取至少 41 个价格点支持 40 日收益窗口；市场均值按历史成分股逐日计算。缺失/非正价格不被补造成有效原始行情。追加未来行情不改变已有描述符。

src/dataset_ori_onehot.py · 完整同日截面和真实历史

先保留 _infer 的完整特征时间线，筛选连续 20 个交易日的因果输入，再构造批次。禁止跨股票/跨成员缺口拼窗。未来标签只在 forward 后决定损失和指标的监督子集。split 末端的跨界标签被剔除。

src/model_backbone_phitp.py · 三形态、日 IC、固定权重

Original 使用 MSE；Feature 将同一描述符沿所有时间步拼接；TSIL 仅训练损失读取描述符。GAT/MASTER/LSR-IGRU 逐日独立 forward。验证按日 IC 选择、patience=20，默认关闭参数平均；推理按同步 ms/sample 计时。

src/models/*.py · 九骨干与 Feature 兼容

移除九骨干中只服务旧损失的 alpha 参数。MASTER use_gate=False 时保留所有输入列，使追加 Feature 不会被截掉；其余预测结构不增加 TSIL 模块。旧 checkpoint 需重新训练。

search.py / src/run_utils.py · 选择顺序、真 seed 与固定网络

先用 seed2025 Original 选网络；固定后逐 seed/predicate 选 alpha；ones 不参与主表谓词选择。关系模型搜索 2/4/8 完整日，其他模型搜索 256/512/1024 样本。Feature 复用 network manifest；搜索不评估 test。

train.py / configs/ · 只报告真实交易收益

18 配置修复原始次日标签、CSZScoreNorm 和交易参数。选定 checkpoint 直接评估 test。正式回测使用 Qlib 执行器，分开策略绝对收益与超额收益，保存 daily return/cost/bench 和实际持仓。

tests/ / scripts/ / requirements.txt · 可重复证据与可运行环境

独立数值 oracle、真实 GAT 未来缺失回归、跨模板九骨干、Feature、选择协议及端到端合成 Qlib 运行。固定 Joblib 1.4.2，解决已复现的 Qlib ParallelExt 接口不兼容。完整测试结论以 verification/RESULTS.md 为准。

已接受的约定与验证边界

  • 用户已确认窗口：Momentum 5/10/20；Volatility 10/20/40；Cycle、Phase、Distribution 20 日；Alpha158 输入 T=20。
  • 用户已确认关系批量：GAT、MASTER、LSR-IGRU 使用 2/4/8 个完整交易日，不能把它们误标成普通 stock batch_size。
  • 已完成合成 Qlib 验通：56 股、120 日、三形态各 504 个测试预测、10 日 Top-50/Drop-5 实际回测，含原始标签、滑点、成本、整手与停牌/阈值检查。
  • 不是历史业绩复现：配置目录没有真实 CSI300/CSI800 数据；未运行全量九模型、五种子的市场实验，未证明旧表格或论文优势结论。
  • 交易限制：信号下一步执行；0.095 是 Qlib 统一涨跌停近似，未验证板块/ST 的逐日规则；整手换算要求有效 factor。
  • 口径与环境：weekday/month、等权市场收益、跨 seed 验证均值、252 日算术年化均明确披露；实测 PyTorch 2.3.1 CPU / Qlib 0.9.6，非原文旧环境或 GPU 延迟复现。
